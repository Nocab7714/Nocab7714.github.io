2024 六角切版直播班心得

發表於 2024-09-08 Disqus：

當初為什麼報名這堂課？

過去曾上過六角的的前端全套課程，也參加過 2022 的 vue 直播課程，做完 vue 店商網站後在後續準備轉職的過程因為發現自己的熟練度不夠，以及想要去的公司多使用 React 框架，思考過後決定參加為期九個月的 React 的前端直播課程提升自己的實力，也順便學習 React 框架。

第一週~第八週的學習過程 - 最大的收獲是？

這次的切版直播班讓我學習到最多的地方，是在第六周的任務作業。過去的學習中我知道 Bootstrap 的框架可以設定很多的變數，不過我沒想到的是，竟然可以設定這麼多的變數！！過去的開發頂多依照設計稿先將 space、font-size 及部分的元件進行變數上的設定，不過在看過當周的助教直播影片後，我才發現自己過去為什麼在切版上會這麼的沒有效率了，原來可以在開發前，可以先依照設計稿將所有的「全域變數」統一先設定好，比如標題的文字間距、行高、顏色、字重等等，就不用像過去一直幾乎使用通用類別進行設定，大大的提升切版時的效率。

最喜歡直播班的哪些活動？

其實要講最喜歡的活動，我覺得是每周五晚上的直播課，因為大家可以跟卡柱老師、同學互相交流哈拉打屁，還可以看老師不斷的翻車 （重點誤），比起自己學習更加的放鬆有趣。

如果時光能倒流，會希望自己再次注意哪些細節？

注意的部分我覺得是在學習時期間的精力管理上能夠在做的更好一點。每當在寫程式時會很容易進入心流狀態，即便倒數的番茄中響了好幾次，自己卻不願意休息，有時候在電腦桌前一坐就是 2、3 個小時，導致我時不時的會因為長期的固定姿勢發生經常落枕的問題。所以接下來要好好的在調整一下，學習讓自己把休息這件事情把在最前面。

對課程的建議或鼓勵？

我覺得比起之前參加 2022 Vue 的直播班體驗來的更好，上次參加直播班的經驗是一個人要完成一個專題，並且大約 10 人一組會一起完成每周的小組任務，不過當時在越接近課程尾聲，開會的人只剩下 2~3 個人，有時候只剩下組長一人在線上完成每周的分組任務，並且專題發表的部分，我們這組包含我，沒有半個人在最後的期限內做出專題作品，整組全軍覆沒，我想可能真的是要同時兼職工作還有學習，有些人還要顧及到家庭生活，時間和體力上真的所剩無幾，再加上要獨自一人完成專題，學習進度又跟不上，所以大家的挫折感都非常大，最後都默默地消失了…

我自己本人也是兼職學習，不過因為是 PT 兼職，所以工作時間較為彈性一點，一天大概可以安排４~ 5 個小時的時間學習，可是當時加上還要一邊學習 Bootstrap 5 的框架，所以真的直接原地爆炸了 … 雖然最後還次有把專題電商的作品慢慢補起來了啦~！！（我沒有放棄 ！！

因為我有參加這次的切版專題班，所以我會以切版直播班 + 切版專題班的學習進行分享。那麼為何我會說這次的直播班體驗比較好呢？首先，這次六角有根據之前的學員的學習狀況進行課程上的調整，專題組是 4 人一組，並且是自行依照想要製作的專題題目進行組隊，若要獨自完成專題也是可以，只不過會需要先進行能力程度上的測驗，在期限內完成測驗內容才可以申請單人專題，這樣一來可以讓有一定基礎能力的人有個人挑戰的空間；4 人一組也可以讓初學者能更專心的將精力放在學習切版上，也更有時間可以透過作業的練習進行知識的輸出，並且因為是團體進行專題開發，所以有許多的專題前置作業大家可以一起分工合作，像是我跟我的組員們會一起分擔線搞圖與流程圖的繪製，多人一起討論專題時也比較可以找到網頁地圖設計上流程上的問題等等，雖然說有時會因不同的想法，在討論上會增加較多的溝通時間成本，但整體來說在專題的前置規劃工作所花的時間比自己單幹要來的快一點，而且專題拿到的設計搞搞圖也可以另外增加 3 頁內容，真的是一兼二顧，摸蜊仔兼洗褲 XD。

還有，這次的組員間的感情比起上次的經驗好太多了！！不會像上次大家都忙於趕進度，每個人都自顧不暇的比較冷漠，這次組員間的互動更加的主動、真實，大家都會在群組中提出自己的需要，互相鼓勵、互相幫助，互相用銃康（誤，真的有覺得在我身旁的都是戰友的 feel，也謝謝專題教練在每周的學習進度中給予我們回饋與鼓勵！！讓我們可以更有動力的繼續學習！！

還有還有，由於是共同開發專題，會需要練習 git flow 的部分（這也是我選擇團體專題的主要原因），可以讓我們實際進入業界工作前，就先有機會練習使用 Git 與 Github 進行團體專案的板控，這是我過往學習錄製課程所沒有辦法體驗到的。

還有還有還有~！！關於設計稿的部分，我有聽之前的學員和網頁設計師鬧不合的經驗，對於拿到設計稿的時間點與品質似乎不是很滿意，所以我有發現到在與設計師溝通使用的「設計師文件」的部分，內容上有更仔細清楚的說明，哪些設計內容是包含在服務項目內的，比如視差滾動的設計是沒有包含在內的，比較大的限制了學員想要天馬行空的設計稿，我覺得這是一件好事，雖然出來的設計稿可能會偏向比較靜態一點的網站，但還是有保留可以製作簡單動畫效果的範圍，也比較不會有初學者在拿到設計稿後製作不出來的尷尬窘境，產生不必要的挫折感。

我覺得這次我們團隊拿到的設計稿品質比起上次的經驗更優質！！這次的設計師設計師還很用心的幫我們想了關於首頁可以製作的動畫效果，並附上了相關的教學與範例網站，配色、還有整體的排版真的都很讓我們團隊驚豔！！希望接下來可以好好的和團隊一起將這份網頁設計稿實做出來完整的網站出來！！

身為學長姐，分享些想入坑的新同學一些勉勵的話

雖然我這麼說有點掃興，但是我覺得還是需要在這邊提醒一下想要參加直播班的學員，如果你的時間上因為工作或其他因素的關係，沒有辦法一天投入超過 4 個小時以上，我會建議身為新手的你，還是不要參加專題班比較適合，就選擇參加直播班的內容就好，因為整體花費的時間與精力真的會超過你的預期，可是如果你真的是一位喜歡挑戰自我的人，還是很歡迎你踴躍的報名加入六角的行列，超乎你扎實的課程內容絕對物超所值~！！只要你願意，只要你不放棄，六角的大家也不會輕易的放棄你！！
